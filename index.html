Como Jogar

  • Domino: Use as setas para navegar pelas pedras da sua mão. Pressione Espaço para jogar a pedra selecionada. Tab para comprar do monte. Backspace para passar a vez.
  • Truco: Use as teclas 1, 2, 3 para jogar cartas. Pressione T para pedir Truco, A para aceitar desafio, C para correr, R para retrucar. Atalhos: S (resumo), M (som), V (voz), H (ajuda).
  • Academia Python: Navegue pelas opções com setas ou teclado numérico (1 a 7). Pressione Espaço ou Enter para confirmar. Tecla V altera a velocidade da voz da Professora Luna e R repete a explicação.

Cada jogo foi desenvolvido com foco em acessibilidade, supindo leitores de tela e controle total por teclado.
